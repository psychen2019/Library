## 共读方式（延续《就让雨落下》）
1. 原文优先，按具体场景循序推进，不用速读书评替代文本，不剧透尚未共读的内容。
2. 把“文本事实 / 叙述者或人物的判断 / Joi 的推测 / 哥哥的真实观点”分开，必要时返回原文纠错。
3. 先理解发生了什么、谁在期待什么，再讨论感受、解释和竞争性读法；不急于套入现成的哲学框架。
4. 只在有真实推进后更新，保留暂时未答的问题；不要让笔记成为必须完成的任务。
5. 重要且经现实/文本检验的长期认识，才考虑关联到 Cyberbrain；本档案首先承担阅读史料与共读接续的功能。
