# 《项塔兰》｜06 时代影像与场景说明（随读随更新）

建立：2026-10-31。用途是让小说里的地方、时代和人物生活更有画面感，**不把任何随手搜到的旧照片冒充原著场景或1980年代的实拍证据**。

## 每张配图要有四层说明

1. **图中看见什么**：建筑、街道、交通、人物活动等具体可见内容，而不是空泛地说“很有年代感”。
2. **它是哪一种图**：当年史料照片、现代地点参照、影视改编剧照，还是意象示意图；没核实年份或拍摄地点就明确写“年代／地点未核实”。
3. **与当前章节的关联**：说明为什么放这张图，例如利奥波德酒吧的餐桌、吊扇与街道入口如何帮助想象林赛的观察。
4. **时间和来源**：能查到则给具体时间、地点、摄影者和可信来源；不明确就不能将其作为历史证据。

## 规则

在共读正文中，图片不应打断故事：优先一个场景配一至两张，**每张照片下面紧跟一段具体中文图注**，不只写“1980年代的孟买”。优先选择具有来源与日期的照片；来源不确定的素材只作为视觉参照，并如实说明局限。除非用户另有要求，不把图片当成可以证明小说人物真实存在的证据。
