## 共读约定
1. 逐章、每次只推进一个合理的短段；讲清具体发生了什么，再讨论人物动机。用户想继续便继续，不用连续提问阻断阅读。
2. **严禁剧透**：后台已知的后文不能进入当前章节的讲述。第一章开头叙述者自己的前瞻性自述属于原文，但不加后续具体情节。
3. 明确区别原文事实、叙述者判断、Joi 推测、用户观点。未观察到的心理或行动不能自行补写。
4. 在讨论文化、贫困、宗教与救赎时，不把一位外国叙述者的观察当成印度全貌；同时避免以批评取代故事。
5. 公开 GitHub 不上传原书正文或大量受版权保护文本；记录原创梗概与简短引文。
6. 对话有实质推进后同步进度，必要时修正早先误读。
