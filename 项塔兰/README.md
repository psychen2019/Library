## 共读约定
1. 逐章推进，每次讲述相对完整的叙事片段；采用自然连贯的长段落，减少短句和刻意拔高，只在有价值时讨论人物动机。用户想继续便继续，不用连续提问阻断阅读。
2. **严禁剧透**：后台已知的后文不能进入当前章节的讲述。第一章开头叙述者自己的前瞻性自述属于原文，但不加后续具体情节。
3. 明确区别原文事实、叙述者判断、Joi 推测、用户观点。未观察到的心理或行动不能自行补写。
4. 在讨论文化、贫困、宗教与救赎时，不把一位外国叙述者的观察当成印度全貌；同时避免以批评取代故事。
5. 公开 GitHub 不上传原书正文或大量受版权保护文本；记录原创梗概与简短引文。
6. 对话有实质推进后同步进度，必要时修正早先误读。

## 长期共读：四层记录法（2026-10-29 确认）
用户明确同意将以下四层记录作为每次共读的固定规则：
1. **剧情事实**：只记录截至当前断点原文中实际发生的事件，必要时附 EPUB 章节和场景定位，不混入未读内容。
2. **人物状态**：记录人物此时知道什么、相信什么、担忧什么以及关系变化；标记推断和不确定性，禁止以后续剧情倒灌。
3. **我们的讨论**：准确区分“用户明确提出的观点”“Joi 的理解和假设”“尚待验证的问题”，不替用户补写看法。
4. **准确阅读断点**：章节、对应原文的具体事件或对话，以及下一段起始场景；不要仅写泛泛的“第一章”。

### 操作顺序
- 每次开始：先查 GitHub 的进度与讨论记录，再打开资料库原版 EPUB 核对断点附近原文。
- 每次共读：小步讲述，故事优先，避免提问打断和后续剧透；清楚区分文本事实与解读。
- 每次结束：尽可能同步四层信息至 GitHub；如写入失败，明确说明，不能宣称已同步。
- 全书研究笔记单独保管并明确剧透警示，不当作用户已读进度。

## 新增共读方法：双重时间线（2026-10-31）
用户提出：希望了解小说故事的大致年份、当时印度的社会环境，并与同时期中国的经济社会情况并置，以增加代入感。今后采用**主线故事 + 同期历史暗线**：以当前章节为主，只在相关场景适度补充印度、中国乃至世界的同期史实；明确区分小说事实、历史来源和推断，不剧透，不把孟买等同于整个印度，也不把某个中国城市等同于全国。

已确认的时代框架：出版方称作者原型经历发生于20世纪80年代初；目前第一章尚未确认林赛抵达孟买的精确年份，以**约1980年代初、1982年前后作为比较参照，不宣称小说精确标年**。参考 https://hachetteindia.com/Home/bookdetails/Info/9780349117546/shantaram 。1982年孟买纺织业大罢工波及约25万工人，说明当地工业与社会矛盾复杂，来源 https://www.labourfile.com/section-detail.php?aid=417 。同期中国农村家庭联产承包责任制扩展、1982年十二大和宪法等历史背景，参考 https://www.worldbank.org/content/dam/Worldbank/document/China-2030-complete.pdf 、https://cpc.people.com.cn/GB/64162/64168/64565/65448/4429492.html 、https://en.moj.gov.cn/2021-06/22/c_634901.htm 。

注意：历史对照用于解释具体生活场景的社会经济条件，避免宏大叙事吞没人物，也不将国外贫困景象浪漫化。用户尚未就这些比较提出独立结论。

## 2026-10-31 新增三个长期维护档案
- **人物与关系**：读到谁就补谁，区分亲见、本人叙述、他人传闻、叙述者推断；不从全书背景研究里偷带剧透。
- **思想与短句**：只记录本次读过的原文极短锚点，配说话人、场景、语境、Joi暂时解释、反例及用户真正表达的评价；特别追踪第二章林赛“说不”的自由和卡拉“说是”的自由，**不替任何一方提前下定论**。
- **图片和历史感**：配图必须说明**图中看见什么／史料还是现代参照／与本章关联／时间来源与未核实之处**；不把现代照片标成1982年的实拍。优先少量图片和有内容的长图注。
- **进度**：对源 EPUB 的42章正文做字符量计算，目前读至第二章约第258段，约42,922／663,291字符，**约6.5%**（基于当前 EPUB 文本提取的粗略字符比例，非出版字数统计）。避免沿用之前未经计算的5.5%。
